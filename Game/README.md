# Education Station Games

## Purpose

This folder documents small, playful interactive experiences that help young learners practice skills from the Education Station curriculum. The first concept is a short, two-dimensional Letter Adventure game designed to run in a desktop browser, so families can try it without installing software or using a game console.

The initial goal is to shape and validate one usable learning experience: a child can understand a brief prompt, take a simple action, receive encouraging and useful feedback, and try again. Early drafts should keep sessions short, interactions clear, and mistakes low-pressure. The experience should support caregiver involvement while allowing a child to make choices independently where possible.

## Structure

- `letter-adventure/` contains the design notes and flows for the Letter Adventure concept.
- `letter-adventure/letter-a-flow.md` sketches the first letter activity, including its screen sequence, child actions, feedback, and next attempts.

Design documents are the starting point for discussion and prototyping. They should capture the learning intent and observable child experience before implementation details are settled. Keep early flows small and testable; revise them based on what children and caregivers can understand and do.

## First concept: Letter Adventure

The first flow introduces uppercase **A** and lowercase **a** through a familiar word, **apple**. The child identifies the target letter, follows a simple letter path, and connects the letter with the word. A correct choice moves the adventure forward; an incorrect choice gives a gentle cue and another chance.
